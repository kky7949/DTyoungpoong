# 데이터 보관

| 위치 | 용도 | 현재 포함 여부 |
| --- | --- | --- |
| `raw/` | 전달받은 원본 데이터와 RAW 시트 보관 | 실제 데이터 없음 |
| `processed/` | CLEAN, 대치로그·대치요약, 데이터 품질 검증 결과 보관 | 실제 데이터 없음 |

두 폴더는 보관 위치만 유지합니다. 원본·정제 데이터 및 Excel 산출물은 `.gitignore`로 Git 추적에서 제외합니다.

## 확인된 전처리 결과

- 원료 성분 7개는 원료등급별 Train 중앙값으로 대치했습니다. 등급·성분별 관측값이 5개 미만이면 전체 Train 통계를 사용했습니다.
- 공정 조건은 전체 Train 중앙값으로 대치했습니다. 황산투입량 930.5 L, 침출온도 67.7 °C, 침출시간 4.09 hr입니다.
- 최종 보고된 CLEAN은 420행×24열이며 파생변수 8개의 계산 정합성을 확인했습니다.
- 분석일자 결측 21개는 별도 미완료 항목입니다. 모든 열의 결측과 물리적 허용범위까지 검증이 끝났다는 뜻은 아닙니다.

위 결과를 생성한 데이터와 실행 코드는 아직 이 저장소에 없습니다. 실제 자료를 가져올 때 원본을 유지하고, 대치 전후 값·Train 통계·데이터 분할·검사 결과를 함께 기록합니다. 외부 공개 범위는 자료의 공유 조건을 확인한 뒤 결정합니다.

상세 수치와 검증 한계는 [진행상황 보고서](../docs/REPORT.md)를 참고합니다.
