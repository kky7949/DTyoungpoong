## 11월 19일 체크포인트

- 기본 실행 씬은 `FactoryDemoExhibitionApi`입니다. 이전 네 시연 씬도 비교와 로컬 시연에 사용할 수 있습니다.
- 공정 조건과 회수율은 수신값을 표시합니다. 시연 애니메이션은 고정된 단계와 시간으로 재생되며, 조건을 실제 반응이나 물성에 매핑하는 작업은 남아 있습니다.
- 카메라·코드 정리 이후에는 실제 HMI 재시험, 최신 macOS 앱 재빌드와 실행, 복원한 Git 체크아웃에서의 Play 확인이 남아 있습니다.
- 로컬 공정과 웹 명령이 겹쳐 웹 명령이 거절되면 오류 응답 접수 전까지 진행 라벨이 잠시 웹 공정으로 표시될 수 있습니다. 11월 19일 검토에서 확인한 기존 표시 문제입니다.
- 저장소의 두 신규 씬에서 Alembic 임시 메시를 제거했습니다. API 씬의 팀 내부 Base URL은 빈칸으로 저장했습니다. 전시용 유리 재질은 로컬에서 제공 원본을 바탕으로 복원합니다. [실행 및 복원 절차](README.md)
