## 현재 저장소와 검증 범위

- GitHub 커밋 `b9220f7`과 `27644ed`에 11월 19일까지의 씬과 스크립트가 있습니다. 이번 반영은 이후 수정된 API 씬, 기본 실행 씬 `FactoryDemoExhibitionApiNatural`, 시작 화면 서버 설정과 macOS 빌드 코드입니다.
- 공정 조건과 회수율은 수신값을 표시합니다. 시연 애니메이션은 고정된 단계와 시간으로 재생되며, 조건을 실제 반응이나 물성에 매핑하는 작업은 남아 있습니다.
- 11월 24일 모델·웹·Unity Editor 시험과 25일 독립 앱 시험은 같은 Mac에서 수행했습니다. 전시 네트워크에서의 재검증, Windows 빌드·실행, 공개 체크아웃에서 제공 에셋을 복원한 뒤의 Play 확인은 남아 있습니다.
- 로컬 공정과 웹 명령이 겹쳐 웹 명령이 거절되면 오류 응답 접수 전까지 진행 라벨이 잠시 웹 공정으로 표시될 수 있습니다. 11월 19일 검토에서 확인한 기존 표시 문제입니다.
- 공개용 API 씬 두 개는 내장 Alembic 임시 메시를 제거하고 Base URL을 비웠습니다. Natural의 주소 예시는 공개용 예시로 바꿨습니다. 빌드와 발표자료용 캡처는 로컬에서 관리하며, 전시용 유리 재질은 제공 원본에서 복원합니다. [실행 및 복원 절차](README.md)
