# A·B·C 연동 확인사항

[대시보드 실행 안내](../README.md), [API 계약 초안](api-contract-draft.md), [Unity 연동 예제](../integration/unity/README.md)에서 현재 구현을 확인할 수 있다.

## 확인한 사항

- B에서 실제 A 모델 `YP-curve17-dev357-v2`의 예측·추천을 HTTP로 호출하고 대표 입력의 결과를 대조했다.
- 실제 A 분석은 원료 성분 7개와 투입량이 필수다. 직접 예측에는 황산량·온도·시간도 필요하다. 입력값의 허용 범위는 [API 계약의 필드 표](api-contract-draft.md#필드와-실제-a-허용-범위)에 있다.
- 모의 분석과 Unity 명령의 기본 원료 필드는 `null`을 허용한다. 실제 A 분석에서 필요한 입력은 별도로 검사한다.
- Unity 명령에는 원료 이름·성분·투입량, 최종 공정 조건, Ni·Co 예상 회수율을 담는다. B의 명령·상태 API와 .NET 데이터 계약 검증을 완료했다.

## 팀에서 확인할 사항

- **Unity 시연 환경.** C가 사용할 Unity 버전과 빌드 대상에서 C# 예제의 컴파일, HTTP 연결, UI 표시를 확인한다.
- **Unity 씬 동작.** 전달된 조건이 실제 씬의 설비 변화와 진행률에 어떻게 반영되는지 확인한다. 완료·오류 보고와 중단 시 처리 방법도 함께 점검한다.
- **시연 네트워크.** 시연에 사용할 장치에서 A·B·C가 모두 연결되는지 확인한다. 필요하면 명령 조회·보고 간격과 B의 연결 판정 시간(개발 기본값 10초)을 실제 시연에 맞춘다.
- **통합 시연.** 실제 A로 추천 또는 예측 → 대시보드 적용 → Unity 수신 → 진행률·완료 보고까지 같은 입력으로 확인한다.
- **분석 설명.** XAI를 추가하기로 하면 A의 설명 응답 형식과 B 화면의 표시 방법을 정한다.
