# Module 3 공정 조건 최적화

향후 공정 조건 추천·최적화 기능을 통합할 상위 폴더입니다. 현재 확인된 자료에는 실제 최적화 구현·검증 완료 근거가 없으므로 실행 스크립트는 두지 않습니다.

Ni·Co 예측 모델과 허용 공정 범위를 확정한 뒤 목적함수, 제약조건, 평가 방법을 정합니다. 기존 예제의 고정 온도·황산량·시간·교반속도 범위와 목표 회수율은 검증된 조건으로 채택하지 않습니다.

웹에서 모의 추천 조건을 표시한 결과와 실제 최적화 알고리즘의 계산 결과를 구분합니다. 실제 기능을 개발할 때 필요한 코드만 추가합니다.
