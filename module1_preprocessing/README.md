# Module 1 데이터 전처리

프로젝트에서 수행한 전처리의 처리 기준을 정리한 폴더입니다. 실제 수행 코드와 Excel 산출물은 아직 이 저장소에 통합하지 않았습니다.

## 확인된 작업

- 배치ID 순서로 Train/Validation/Test 70/15/15 분할. 대치 통계는 Train에서만 계산.
- Ni·Co·Li·Mn·Cu·Fe·Al 7개 성분의 평균·중앙값 대치 비교. Validation 완전행 41개 마스킹, 5회 및 30회 실험 후 중앙값 선택.
- 원료 성분 211개, 공정 조건 80개 결측 대치. 최종 CLEAN 420행×24열 생성.
- 불순물합계, Ni/Co 함량비, 황산/원료비, 온도시간 지표, Ni·Co 투입량, 목표금속 투입량, 불순물/목표금속비의 8개 파생변수 계산 검증.
- 기본 품질 검증·시각화 수행. 등급별 IQR 이상치 후보 탐지 수행.

## 남은 작업

RAW 데이터사전 기준 최종 이상치 처리 검증, 분석일자 21개 결측 처리 방침, 최종 전처리 전체 정규화·표준화 검토가 남아 있습니다. IQR 후보 0건을 실제 공정 허용범위 검증 완료로 해석하지 않습니다.

기존 KNN 중심 예제와 임의의 활성화에너지를 넣은 파생변수 코드는 실제 채택한 처리 방식과 달라 제거했습니다. 실제 수행한 코드를 가져올 때 필요한 파일만 추가합니다. 현재 실행할 전처리 파이프라인은 없습니다.
