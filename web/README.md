# 디지털 트윈 웹과 서버

## 담당과 현재 상태

김용준이 React/TypeScript 사용자 화면과 FastAPI 중계 서버를 개발하고 있습니다. 실제 프런트엔드·서버 소스는 아직 이 저장소에 통합하지 않았으며, 현재는 상위 폴더와 안내만 둡니다.

## 프로젝트에서 확인된 범위

- 원료 이름, Ni/Co 함량, 투입량, 황산량, 침출 온도·시간 입력.
- 현재·추천 조건과 예상 회수율의 표·그래프 비교. 미입력 숫자는 null로 전달하고 서버가 임의 보정하지 않음.
- 추천값 반영·수정, 조건 변경 후 재분석, 최종 확정 조건 표시와 적용 요청.
- Unity의 명령 조회·상태 보고를 위한 통신 구조, 대기·실행 중 추가 적용 제한, 이전 상태의 덮어쓰기 방지, 상태 조회 재시도.
- 모의 데이터와 Unity 대역 스크립트로 입력부터 적용 요청, 실행 중·완료 상태 반영까지 확인.
- 노트북·태블릿 기본 조작 확인. 좁은 화면의 비교표는 가로 스크롤 발생.

**실제 AI 모델과 Unity 프로젝트는 아직 연결하지 않았습니다.** 위 상태 반영은 실제 Unity 공장 실행을 검증한 결과가 아닙니다.

## 연동 전 검토할 사항

- 분석 조건과 실행 조건의 일치 여부는 현재 화면에서만 검증. 서버의 분석 ID·당시 입력값 검증 필요 여부 결정.
- 명령 조회 즉시 큐에서 삭제하는 구조의 유실·중복 실행 가능성. 수신 확인과 중복 방지 구현 순서 결정.
- 같은 Wi-Fi에서 로그인 없이 요청 가능한 시연 환경의 인증·조회·제어 권한 범위 결정.

실제 소스를 가져올 때 프런트엔드·서버 폴더, 패키지 정의와 잠금 파일, 실행 절차, 모의 검증 절차를 함께 추가합니다. 미리 빈 `App.tsx`, `main.py` 등을 만들지 않습니다.
