# 실험 노트북

현재 이 폴더에 실제 노트북은 없습니다. EDA·대치 검증·파생변수 비교·Model1 과적합 진단에 사용한 기존 노트북을 정리해서 추가할 위치입니다.

진행되지 않은 실험의 이름만 붙인 빈 노트북은 만들지 않습니다. 실제 노트북을 추가할 때 다음을 기록합니다.

- 입력 데이터와 시트, 배치ID 기준 Train/Validation/Test 분할
- Train에서만 계산한 대치 통계와 무작위 시드
- 실행 순서, 의존성, 생성하는 산출물
- 평가 구간과 지표, 후보 비교와 재학습 결과의 구분

데이터와 모델 결과물은 노트북에 포함해 공개하지 않고 [데이터 보관 기준](../data/README.md)에 따라 별도로 관리합니다. 현재 확인된 실험 결과는 [진행상황 보고서](../docs/REPORT.md)에 있습니다.
